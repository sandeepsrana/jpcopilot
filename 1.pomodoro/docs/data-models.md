# データモデル

## 現状

現在（Phase 0）の実装では、サーバー側のデータモデル（DB スキーマ・Python モデルクラス）は存在しません。  
Flask は静的な HTML ページを配信するのみで、データの永続化は行っていません。

---

## 将来のフロントエンド状態モデル（設計）

タイマー状態はフロントエンドの JavaScript で管理する予定です。  
以下は設計書（`../architecture.md`）に基づく状態モデルの定義です（未実装）。

### タイマー状態

| フィールド       | 型                                      | 説明                                           |
| ---------------- | --------------------------------------- | ---------------------------------------------- |
| `phase`          | `"focus" \| "shortBreak" \| "longBreak"` | 現在のフェーズ                                 |
| `isRunning`      | `boolean`                               | タイマー動作中かどうか                         |
| `remainingSec`   | `number`                                | 残り時間（秒）                                 |
| `cycleCount`     | `number`                                | 完了した作業フェーズ数（長休憩判定に使用）     |

### タイマー設定（`durations`）

| フィールド       | 型       | 説明                   |
| ---------------- | -------- | ---------------------- |
| `focusSec`       | `number` | 作業フェーズの長さ（秒） |
| `shortBreakSec`  | `number` | 短休憩の長さ（秒）     |
| `longBreakSec`   | `number` | 長休憩の長さ（秒）     |

### 当日統計（`statsToday`）

| フィールド        | 型       | 説明                                    |
| ----------------- | -------- | --------------------------------------- |
| `dateKey`         | `string` | 日付キー（例: `"2025-06-01"`, YYYY-MM-DD形式） |
| `completedCount`  | `number` | 完了したポモドーロ数                    |
| `focusTotalSec`   | `number` | 当日の累計集中時間（秒）                |

---

## 永続化方針

| フェーズ   | 永続化先      | 対象データ             |
| ---------- | ------------- | ---------------------- |
| Phase 1    | LocalStorage  | タイマー設定・当日統計 |
| Phase 2    | Flask API + DB | 統計データ（サーバー保存） |

LocalStorage への保存・読み出しは JavaScript 側で実装します（未実装）。
